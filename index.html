공유 저장소 (여러 사람이 같은 기록에 저장)

관리자가 보낸 공유 링크로 들어왔다면 공유 암호만 넣으면 돼요. 관리자는 아래 세 칸을 모두 채운 뒤 공유 링크 복사로 다른 사람에게 보내 주세요.

농촌진흥청 작물·병해충·농약 정보

무료 키 2개를 넣고 전체 내려받기를 한 번 누르면 농진청에 등록된 작물·병해충 목록과 등록농약 정보(약 9만 건)를 PC에 저장해요. 10~20분 걸리고, 그 뒤로는 인터넷 없이 찾아볼 수 있어요.
① 병해충 키: 국가농작물병해충관리시스템(NCPMS) 회원가입 › OpenAPI 신청
② 농약 키: 농약안전정보시스템(PSIS) 회원가입 › 공공데이터개방 › OpenAPI 신청

휴대폰용 DB 파일 내보내기

실시간 조회: 공유 저장소에 연결되어 있고 관리자가 농진청 중계 함수를 만들어 두었으면, 작목을 넣는 순간 농진청 병해충 목록·상세정보·등록농약을 바로 불러와요. (인터넷 필요)

인터넷 없이 쓰려면 PC에서 만든 DB 파일을 가져오세요.

카카오지도 · 도로명주소

키가 없으면 무료 OpenStreetMap 지도로 동작해요. 카카오지도와 도로명주소 자동 변환을 쓰려면 카카오 개발자센터에서 앱을 만들고 JavaScript 키를 붙여넣으세요. (무료)

사진 AI 추론

공개 모델(PlantVillage 38종, Apache-2.0)을 기기 안에서 실행해요. 키·요금 없음, 처음 한 번 약 13MB를 받은 뒤로는 인터넷 없이도 돼요.
학습 작목: 사과, 포도, 복숭아, 딸기, 고추(피망), 토마토, 감자, 옥수수, 콩, 호박, 체리, 블루베리, 감귤, 라즈베리. 실험실 잎 사진으로 학습해서 현장 사진은 오차가 있을 수 있어요.

Google AI Studio에 구글 계정으로 로그인 › Create API key로 무료 키를 받아 붙여넣으세요. 결제 등록 없이 하루 사용 한도 안에서 무료이며, 무료 등급에서는 보낸 사진이 구글 서비스 개선에 쓰일 수 있어요.
